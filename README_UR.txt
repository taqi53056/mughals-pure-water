- index.html

اہم: ایپ ابھی خودبخود انٹرنیٹ پر شائع نہیں ہوئی۔ اسے چلانے کے لیے HTTPS ویب ہوسٹنگ درکار ہے۔

ڈیٹابیس کا ایک ضروری مرحلہ:
1) Supabase کھولیں اور SQL Editor میں جائیں۔
2) record_product_sale.sql کی مکمل عبارت چلائیں۔
3) اس کے کامیاب ہونے کے بعد ہی نئی ایپ کی سیل محفوظ کرنے والی سہولت کام کرے گی۔

اس SQL فنکشن میں سیل اور متعلقہ کارٹن مزدوری ایک ہی ڈیٹابیس ٹرانزیکشن میں محفوظ ہوتی ہے۔
اگر دونوں میں سے کوئی اندراج ناکام ہو تو پوری کارروائی واپس ہو جاتی ہے۔

PWA فائلیں HTTPS پر ہوسٹ ہونے کے بعد ہی Chrome میں انسٹالیشن/Service Worker فعال ہوں گے۔
